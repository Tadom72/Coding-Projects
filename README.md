  ### 💻 **<ins>Web Development</ins>**
  
  - **Website-with-Database-Project:**
    A library website that would interact directly with a database. Created using **PHP**, **SQL**, **HTML** and **CSS**. The website and database were ran off xampp.
    The website would be used by two different users, an admin and a customer. The admin had the ability to add and remove books from the database.

### ☕ **<ins>JAVA</ins>**
  - **Library App:**
    A library program in which can read and update a text file that contains the a list of books and their authors available in the library.
    The user is presented by menu where they can load books from a file, view list of loaded books, add books and save to a text file named "books1".
    The program had the ability to create a new file with the loaded booklist if no "books1" existed. This project taught me the **importance of OOP Principles** like
    Abstraction, Encapsulation, Inheritance and  Polymorphism.
    
  - **Algorithms:**
    A calculation program that would read a weighted or unweighted graph that has been translated into numbers in a text file.
    The text file would be read by the program, create an adjacency list from the information and then the program would traverse the graph using Depth First,
    Breadth First Or Prims Algorithm.
